# Inbox

The inbox is a unified notification center for everything your agents surface: decisions, blockers, completed work, and items that need human review.

## Priority Tiers

| Priority | Description | Examples |
|---|---|---|
| `urgent` | Needs immediate attention | Agent error, security alert, budget exceeded |
| `high` | Review soon | Task completed, approval request |
| `medium` | When you have time | Status update, suggestion |
| `low` | FYI | Activity log, minor update |

## Inbox Actions

Each inbox item supports:

- **Approve** — Accept the agent's work or request
- **Reject** — Send back with feedback
- **Convert to Task** — Turn it into a tracked task
- **Dismiss** — Mark as read and archive

## Bulk Operations

Select multiple items and:

- Approve all
- Dismiss all
- Convert selected to tasks

## Triage Flow

The inbox is designed for fast triage:

1. Open inbox (sorted by priority)
2. Review each item
3. Take action (approve, reject, convert, dismiss)
4. Items flow into the task board or get archived
