# Mobile Distribution Templates

These templates are starting points for private deployment.

- `apple-business-manager-checklist.md`: custom app/private app readiness checklist
- `managed-google-play-checklist.md`: Managed Google Play private app readiness checklist
- `intune-ios-appconfig.example.json`: example managed app config payload for iOS distribution
- `intune-android-appconfig.example.json`: example managed app config payload for Android distribution
