# Apple Business Manager Checklist

- Use an organization-owned Apple Developer account.
- Set the final bundle identifier before submission.
- Confirm the app display name matches the organization's brand.
- Generate final icon and splash assets from the org manifest.
- Confirm support contact and escalation ownership.
- Prefer Custom Apps in Apple Business Manager for employee-only distribution.
- If devices are MDM-managed, confirm assigned groups and update policy.
- Test bootstrap via deep link and managed configuration on a clean device.
- Verify Tailscale reachability before login if the server is tailnet-only.
