# Managed Google Play Checklist

- Use an organization-owned Google Play Console account.
- Set the final Android application ID before private rollout.
- Confirm signing key ownership and rotation process.
- Prepare a private app listing name and internal support contact.
- Decide whether app updates are automatic or staged by device policy.
- If using MDM, verify assignment to the correct Android Enterprise groups.
- Test bootstrap payload intake and deep-link open on a clean device.
- Verify Tailscale reachability for tailnet-only deployments before user login.
